## MVP Statement

> A student enters their courses, assignments and exam dates and gets back a **prioritized weekly study plan** with **Pomodoro sessions** and an **academic risk analysis**, generated by **Gemini**, saved in **Tiger Data** and shareable to **Discord**.

The MVP focuses on **one core workflow done well**:

```text
Enter assignments → Generate plan (Gemini) → View results → Save (Tiger Data) → Share (Discord)
```

### Must have (MVP core)

### MVP constraints and assumptions

- **No login:** the MVP is single-session and anonymous; history is global for the demo.
- **Manual input only:** no calendar or LMS import.
- **English only**, desktop and mobile web browsers.
- **Free tiers:** Gemini API, Tiger Data, Vercel and Render free plans.
- Pomodoro = 25 minutes focus + 5 minutes break.

## 2. Out of Scope

These are intentionally **not** built for HackUTA. They are listed in the README under *Future Improvements*.

| Item | Reason | Future phase |
|------|--------|--------------|
| User accounts and authentication | Adds time and security work; not needed for the demo | Phase 2 |
| Google Calendar / Outlook sync | External OAuth integration is too large for the timeline | Phase 2 |
| Canvas / Blackboard (LMS) import | Requires institution access and APIs | Phase 3 |
| Native mobile app | Responsive web app covers mobile for the MVP | Phase 3 |
| Push / email / SMS reminders | Discord covers notifications for the MVP | Phase 2 |
| GPA tracking and grade prediction | Needs grade data and more modeling | Phase 3 |
| Dallas College specific resources | Needs partnership and content curation | Phase 3 |
| Learning analytics across many users | Needs accounts and real usage data | Phase 3 |
| Payments or premium plans | Not relevant for a hackathon MVP | — |
| Multi-language support | English only for the MVP | Phase 3 |

### Scope control rules

1. **No new Must-have features after Sprint 4.** New ideas go to the *Out of Scope* table.
2. **Should-have features start only after all Must-haves work end to end.**
3. **Could-have features start only after deployment (Sprint 10) is done.**
4. If time is short, cut in this order: C-2 → C-1 → S-3 → S-2 → S-1.

## 3. HackUTA Strategy

### Target prize categories

| Category | How we win it | Proof in demo |
|----------|---------------|---------------|
| **Best Use of Gemini API** | Gemini is the core engine: plan generation, prioritization, risk explanation, all as validated structured JSON | Show prompt → structured JSON → UI cards |
| **Best Use of Tiger Data** | Every request and AI result is stored in PostgreSQL; history and dashboard analytics are queried from it | Show history page and KPI dashboard backed by live queries |
| **Build with SpaceXSI** | AI-assisted development with Cursor AI; documented engineering process (12 sprints, issues, milestones) | Show repo, sprint workbook and commit history |
| **Overall / Best Student Hack** | Real, relatable student problem with a working, deployed product | Live demo on production URL |

### Judging focus

| Judging area | Our answer |
|--------------|------------|
| **Problem** | Students know what to do but not what to do first |
| **Innovation** | AI risk analysis + prioritization + Pomodoro plan in one step, not just a chatbot or to-do list |
| **Technical depth** | Full stack: Next.js, FastAPI, Gemini structured output, PostgreSQL, webhooks, cloud deployment |
| **Completeness** | Deployed and working end to end |
| **Presentation** | Clear 2-minute demo with a relatable persona (Alex) |

### Demo plan (2–3 minutes)

1. **Hook (15 s):** "Alex has a lab due Thursday, a quiz Friday and works 20 hours a week. Where do they start?"
2. **Input (20 s):** Enter 3–4 sample assignments and exams.
3. **Generate (30 s):** Show the priority matrix, Pomodoro plan and risk analysis from Gemini.
4. **Persist (20 s):** Open history / dashboard showing data from Tiger Data.
5. **Share (15 s):** Send the plan to Discord and show the message arriving.
6. **Architecture (20 s):** One slide: Next.js → FastAPI → Gemini + Tiger Data + Discord.
7. **Close (15 s):** Impact and future roadmap.
